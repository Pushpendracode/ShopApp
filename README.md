# 🛍️ Add to Cart App

A React application for browsing and managing a shopping cart using the Fake Store API.

## Features
- Browse 20 products from Fake Store API
- Add/Remove items from cart
- Increase/Decrease quantity
- 10% discount on total price
- React Router navigation

## Tech Stack
- ReactJS
- React Router
- Tailwind CSS
- Fake Store API
